# Initial installation

Before activation, verify and retain a recoverable full WordPress database/files backup and note the active theme, homepage, site title, permalink and visibility settings. WordPress content export alone is not a full backup.

Install the two reviewed packages through WordPress administration, or deploy their directories through the verified SSH workflow. Do not change unrelated themes/plugins or remove default content. Activate the custom theme and companion plugin only after PHP checks and a backup pass.

The plugin provisions Home, How It Works, Why Binteva, Platform, Industries, Commercial Value, About, FAQ and Contact. It preserves pages whose slugs already exist. Configure a primary menu and review every page. Changes to shipped content.php do not overwrite previously provisioned WordPress page content; edit existing pages separately with revisions/backups.

The default booking link is the user's Agency 8200 Calendly URL and remains editable under Settings > Binteva. The contact page identifies the calendar provider. Configure the verified inquiry destination before the form becomes available. Send a clearly labeled test inquiry, confirm inbox receipt and Reply-To, and verify error handling. Confirm privacy/contact details before launch.

Set the site identity to Binteva; verify logo variants and favicon, homepage, permalinks, HTTPS, sitemap, canonical URLs and search visibility. Preserve any preexisting launch restriction. Do not enable nonessential tracking without confirmed IDs and an appropriate consent decision.
